TTESPL ERP - Real Push Notification Setup (jab app band ho tab bhi)
====================================================================

YE KYU ZAROORI HAI
-------------------
Abhi tak app sirf itna karta tha: jab order/payment/delivery hoti hai,
ek record Firestore ke "app_notifications" collection me likha jaata
hai. Lekin koi bhi cheez us record ko dekh kar staff ke phone par asli
push notification bhej nahi rahi thi - isliye:
  - App OPEN ho tab:  JS listener turant chal jaata hai -> popup dikh
                       jaata hai.
  - App band/kill ho: kuch nahi hota, jab tak koi FCM push na bheje.

Yahan diya hua "functions/index.js" wahi missing piece hai. Ye Firebase
Cloud Function hai jo "app_notifications" me naya record banne par,
sabhi saved staff phones (fcm_tokens collection) ko ek asli Android
push bhej deta hai - bilkul WhatsApp/Zomato jaisa, app band ho tab bhi.

ZAROORI SHARTE
----------------
1. Aapka Firebase project ("ttespl") "Blaze" (pay-as-you-go) plan par
   hona chahiye - Cloud Functions free "Spark" plan par nahi chalte.
   Blaze me bhi roz ke chhote se usage (jaisa ki yahan hai) ke liye
   generally koi bill nahi aata (free quota ke andar), lekin card add
   karna Google ki taraf se zaroori sharat hai.
2. Aapke paas Firebase project par Owner/Editor access hona chahiye
   (jis Google account se aap Firebase console kholte ho).
3. Computer par Node.js installed ho (v18 ya v20).

DEPLOY KARNE KE STEPS (apne computer/laptop se, ek baar karna hai)
---------------------------------------------------------------------
1. Firebase CLI install karo (agar pehle se nahi hai):
     npm install -g firebase-tools

2. Login karo (wahi Google account jisse Firebase console kholte ho):
     firebase login

3. Is "cloud-functions-for-push" folder ko apne computer par le jao,
   terminal me usi folder ke andar jao:
     cd cloud-functions-for-push

4. Confirm karo ki project "ttespl" hi select ho:
     firebase use ttespl
   (agar list me na dikhe to: firebase use --add)

5. Functions ke dependencies install karo:
     cd functions
     npm install
     cd ..

6. Deploy karo:
     firebase deploy --only functions

   2-3 minute me "sendPushOnNewNotification" function live ho jayega.

TEST KAISE KARO
-----------------
1. Kisi bhi staff ke phone me app khol kar Notification permission
   "Allow" karo (agar pehle se nahi ki hai) - isse uska FCM token save
   ho jayega.
2. Us phone ko pura band/minimize kar do.
3. Doosre device se ek Order ya Payment record karo.
4. 2-5 second me pehle phone par ek asli Android notification (sound +
   vibration ke saath, lock screen par bhi) aa jaani chahiye - ab wo
   sirf notification panel kholne par nahi, seedhe POPUP/heads-up
   banner ki tarah aayegi.

AGAR POPUP AB BHI NAHI AATA
-----------------------------
Agar push phone tak pahunch raha hai (yaani notification panel me
kabhi dikh jaata hai) lekin heads-up POPUP phir bhi nahi aata, to iska
matlab Android ne us site/app ke liye Notification "Importance" ko
khud "Default/Low" kar diya hai. Fix: Phone Settings -> Apps ->
Chrome (ya jo bhi browser app use karte ho) -> Notifications -> is
site/channel ko dhundo -> Importance "High"/"Urgent" kar do, aur
"Pop on screen" / "Show as banner" on karo.

MAIN YE DEPLOY KYU NAHI KAR SAKA
-----------------------------------
Cloud Function deploy karne ke liye aapke Firebase account me login
karna padta hai (Google account + billing access), jo mere paas nahi
hai. Isliye maine poora ready-made code bana diya hai - upar wale
steps follow karke aap (ya koi bhi developer) ise 5 minute me deploy
kar sakte hain.
